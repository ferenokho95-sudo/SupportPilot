# SupportPilot

AI-помощник оператора поддержки. Работающий локальный проект для портфолио: Python, HTTP API, браузерный интерфейс, тесты и готовый пример отчёта.

## Быстрый запуск на Windows

1. Полностью распакуйте ZIP в отдельную папку. Не запускайте файлы внутри архива.
2. Установите Python **3.11 или 3.12** с python.org (с Python Launcher `py`).
3. Дважды нажмите **START_WINDOWS.bat** и дождитесь строки с адресом сервера.
4. Откройте **http://127.0.0.1:8012** в браузере. Окно консоли оставьте открытым.
5. Для остановки нажмите Ctrl+C в консоли.

При первом запуске создаётся `.venv` и устанавливаются зависимости. Сторонних Python-зависимостей нет; интернет для локальной работы не требуется. Сам Python в ZIP не включён. Если окно сообщает об ошибке, оставьте его открытым и прочитайте сообщение. Если порт занят, запустите `python app.py serve --port 8111` из терминала и откройте указанный адрес.

## Запуск из терминала (Windows / macOS / Linux)

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py serve
# macOS / Linux вместо этого:
# .venv/bin/python -m pip install -r requirements.txt
# .venv/bin/python app.py serve
```

Все дальнейшие команды `python` выполняйте интерпретатором созданного окружения.

## Что реализовано

- Поиск по 8 статьям вымышленного магазина: символьный TF-IDF и cosine similarity.
- Локальный режим возвращает выдержку из статьи с источником.
- Неясный вопрос → уточнение; вопрос вне базы или запрос секретов → передача оператору.
- Дополнительный LLM-режим через совместимый Chat Completions API.
- Проверка JSON и разрешённых ID источников в ответе LLM.
- Оператор принимает, редактирует или отклоняет черновик; история хранится в SQLite.
- 22 проверочных обращения, измерение времени подготовки и автоматических прокси качества.
- Расчёт стоимости по usage и заданным тарифам; неизвестная стоимость сохраняется как null.

## Демонстрация за 2–3 минуты

1. Нажмите «Подготовить ответ» для запроса о двойном списании.
2. Откройте ссылку на источник и проверьте ограничения инструкции.
3. Отредактируйте черновик и нажмите «Сохранить правку»; запись появится в истории.
4. Проверьте кнопки «Уточнение» и «Вне базы».
5. Откройте базу знаний и блок проверки на обращениях.
6. LLM-режим включайте только после настройки переменных окружения из `docs/LLM_SETUP.md`.

## Готовые результаты и повторный запуск

В `reports/example/` уже есть JSON и `REPORT.md` с результатами выполненного локального прогона. Данные синтетические, результаты не выданы за работу с клиентами.

```bash
python app.py demo
python -m unittest discover -s tests -v
```

`demo` пересоздаёт файлы в `reports/example/`. Пользовательские данные интерфейса остаются в `storage/app.sqlite3`. Чтобы начать с нуля, остановите сервер, при необходимости сделайте резервную копию и удалите только папку `storage/`.

## Структура

- `app.py` — CLI и HTTP-маршруты.
- `core.py` — предметная логика и работа с результатами.
- `common.py` — сервер, SQLite, поиск и клиент API (используются нужные проекту части).
- `web/` — HTML, CSS, JavaScript без CDN и сборщика.
- `data/` — исходные демонстрационные данные.
- `tests/` — автоматические проверки.
- `docs/` — описание продукта, API и сценарий дальнейшего тестирования.
- `.github/workflows/tests.yml` — конфигурация CI для Python 3.11/3.12.

## Ограничения

Локальный режим извлекает текст, а не генерирует его нейросетью. Символьный поиск не понимает все перефразировки. Порог поиска .16 и разница .035 заданы заранее для демонстрации. Правила магазина вымышленные, не юридические условия реального магазина. Валидные ID ссылок не доказывают корректность всех утверждений LLM: нужен оператор. Платные API здесь не вызывались. Оценка качества автоматическая; не измерялись время работы человека, удовлетворённость или экономия поддержки. Переадресация обозначается решением, интеграции с helpdesk нет.

Приложение слушает только `127.0.0.1`, рассчитано на одного локального пользователя и не предназначено для публичного размещения без доработки сервера, авторизации и обработки нагрузки. Секреты не включены. Windows BAT и реальные внешние LLM отдельно не запускались; подробности фактических проверок — `docs/VERIFICATION.md`.
