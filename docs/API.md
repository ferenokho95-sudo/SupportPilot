# Локальный HTTP API

Base URL — адрес из консоли. Запросы POST принимают JSON с `Content-Type: application/json`.

| Метод | Путь | Пример тела | Результат |
|---|---|---|---|
| GET | /api/knowledge | — | Статьи базы знаний |
| GET | /api/history | — | До 200 последних обращений |
| GET | /api/evaluation | — | Автоматическая проверка локального режима |
| POST | /api/ask | `{"question":"Где скачать электронный чек после оплаты?","mode":"local"}` | Черновик с ID и источниками |
| POST | /api/review | `{"id":1,"decision":"edit","final_text":"Проверенный ответ"}` | accept / edit / reject, без отправки |
| GET | /health | — | Статус сервера |

Коды: 200 — успех; 400 — неверный ввод; 404 — нет маршрута/записи; 500 — ошибка программы (подробности в консоли). Максимум тела запроса 2 МБ. Сервер принимает Host и Origin только своего localhost-адреса. CORS для других сайтов не включён.
